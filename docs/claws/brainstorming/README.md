# Brainstorming whether to claw

## File structure

Subdirectories herein correspond to sequential tasks as part of our brainstorming. As such:

- Subdirectory names contain both:

    - their number in the sequence
    - a short description of the task
    <p></p> 

    > e.g., [`01-aggregate-and-reframe/`](01-aggregate-and-reframe/)

- Iterations in the execution of a subdirectory's brainstorming task are contained in further subdirectories named `v1/`, `v2/`, etc.

    > e.g., [`01-aggregate-and-reframe/v1/`](01-aggregate-and-reframe/v1/)
