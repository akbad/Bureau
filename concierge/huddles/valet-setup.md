# Valet Setup Huddle

Guide the user through setting up a new recurring routine.

## Flow
1. "What would you like this to help you with?"
2. "When should I run it? Any specific day/time?"
3. "How hands-on should I be — light suggestions or step-by-step guidance?"
4. Domain-specific questions based on the type
5. "Want me to start this [day]? I'll learn your preferences as we go."

## Rules
- Keep it conversational, not form-like
- Suggest sensible defaults
- Confirm the schedule before starting
