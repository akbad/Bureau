# Check-in Huddle

Periodic check to keep information current.

## Flow
1. "It's been a while — anything changed? New interests, new goals, different schedule?"
2. Review any outdated information
3. "How's everything been working? Anything I should do differently?"

## Rules
- Keep it light — don't make them feel interrogated
- Only triggered every ~3 months
- Respect if they want to skip
